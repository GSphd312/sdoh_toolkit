Tableau Dashboard Template

This folder contains a reusable Tableau packaged workbook for the Open Scholarship Toolkit.

File:
SDOH_Tableau_Dashboard_Template_IL.twbx

How to use:
Download the .twbx file.
Open it in Tableau Desktop.
Prepare your data using the Open Scholarship Toolkit reproducible R workflow.
Connect your prepared dataset to the workbook.
Replace the sample data source if needed.
Review the maps, charts, filters, labels, and titles.
Adapt the dashboard for your own project.
Publish the completed dashboard to Tableau Public when ready.

The template is intended to provide a starting structure that learners can reproduce or adapt using data prepared through the Toolkit.
